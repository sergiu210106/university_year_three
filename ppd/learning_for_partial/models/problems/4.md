# Description

consider a matrix A with nxn elements - real numbers, and a kernel matrix K with kxk elements. (k is odd, k << n)

write an MPI program with p (p>2) processes that computes a matrix B obtained by applying a bidimensional convolution on a matrix A with kernel matrix K.

consider p divides n. process 0 simulates teh reading my initializing the matrices with random numbers. matrix B is printed by process 0.

req:

- horizontal distribution
- one element from A is not sent to more than one process. 
- neighbours may communicate using point-to-point.
- process 0 aggregates results

variant A (7 points) No global communications allowed
variant B (3 points) replace point-to-point with global communication where it is possible
