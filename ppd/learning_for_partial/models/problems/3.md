# Matrix-vector multiplication

Let `A` in M_n(Z) be a n-by-n square matrix with integer entries and `x` in Z^n a column vector with n integer entries. Write a MPI program in C/C++ that computes the matrix-vector product y=Ax, using `p` processes (at least 2). the process with rank 0 initializes the matrix `A` and the vector `x` using random values from the interval [0,100) and prints the resulting `y` on the console screen. All processes (including the process with rank 0) are involved in the computation.

# Scoring

- **8p** The process with rank 0 distributes the matrix using the horizontal distribution to the other processes including itself, Suppose that p|n. you must use the appropriate collective operations ( MPI_Bcast, MPI_Scatter, MPI_Gather) to solve the problem.
