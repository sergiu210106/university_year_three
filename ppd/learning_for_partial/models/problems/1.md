# Description

Consider a file `input.txt` containing integers, where the first one represents the number `n` (*how many numbers will be read*) and the remaining ones will be denoted as a_0, a_1, ..., a_{n-1} one number per line. Write an MPI program that computes 2 arrays:

- one (`X`) containing all the positive numbers among the given numbers, in the order they appear in the initial array `A`. 
- the second (`Y`) containing all the negative numbers among the given numbers, in the order they appear in the initial array `A`. 

Array `X` is written  to the file `outputX.txt`, and array `Y` is written to outputY.txt. Only process 0 reads and writes from/on files. All processes should participate to the computation

# Scoring
- **8 points** - provide the code for a variant that assume that `p` (the number of processes) divides `n`, and used MPI_Scatter for data distribution

- **2 points** - analyze and modify the first variant for the case when the condition that assumes `p` divides `n` is not assured.
