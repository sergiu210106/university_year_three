# Description

## `input.txt` contains:
- one line 1 a real number `w`
- one line 2 a positive integer `n`
- `n` real numbers one per line

Launch **P** processes, p_i being the process with index `i` in [0, P-1], that execute:

## Stage 1
- p_0 reads `w` and the `n` numbers
- p_0 broadcasts `w`
- p_0 distributes the data to all processes as equally as possible (p_0 participates in computation)

## Stage 2
- all processes apply on the local blocks the function `h`:
```python3
h(v,w):
    case 1: (v < w) => v = v + w
    case 2: (v >= w) => v = v - w
```

- all processes count how many tiumes case 1 was applied and store it in variable `A`
- all processes count how many times case 2 was applied and store it in variable `B`
- all processes compute the local sum of the transformed values

## Stage 3
- the processes compute the global sum using a cascade: p_0 -> p_1 -> p_2 -> p_3 -> ... -> p_P-1 -> p_0. 
- p_0 received the global sum at the end of the cascade and writes it to the console.

## Stage 4
- all processes send the transformed local block to p_0 and the pair (A,B) to p_1
- p_0 writes the transformed blocks in the original index order to `output.txt`
- p_1 computes the total sum for A and B and prints them to the console.
